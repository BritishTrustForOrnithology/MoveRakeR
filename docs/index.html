MoveRakeR

An R package to source, clean and visualise tracking data

Chris B. Thaxter

British Trust for Ornithology

Abstract

MoveRakeR is an R package developed to facilitate the sourcing, processing, cleaning and visualisation of animal tracking data. The package provides tools to support the preparation and exploration of tracking datasets, helping researchers work with data from different sources within a consistent R-based workflow.
